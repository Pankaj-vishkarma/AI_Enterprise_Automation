# AI Enterprise Automation Platform

AI Enterprise Automation Platform built using FastAPI, PostgreSQL, SQLAlchemy, Alembic, and React.

## Features

* JWT Authentication
* Refresh Token Management
* Role Based Access Control (RBAC)
* Organization Management
* User Management
* Manager & Employee Hierarchy
* PostgreSQL Database
* Alembic Migrations

## Tech Stack

### Backend

* FastAPI
* SQLAlchemy
* PostgreSQL
* Alembic

### Frontend

* React
* JavaScript

## Roles

* SUPER_ADMIN
* ORG_ADMIN
* MANAGER
* EMPLOYEE
